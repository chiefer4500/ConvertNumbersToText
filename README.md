# Number to Text Converter in C++

A lightweight, recursive C++ function that converts integer numbers into their corresponding English word representations (e.g., `12345` to `"Twelve Thousand Three Hundred Forty Five"`).

## 🚀 Features

* **Wide Range Support:** Handles numbers from 0 up to billions.
* **Recursive Breakdown:** Cleanly splits numbers into manageable scales (Billions, Millions, Thousands, Hundreds, Tens, and Units).
* **Clean Spacing & Formatting:** Properly formats exact multiples (like "One Thousand" instead of trailing spaces) and singular/plural scales ("One Million" vs "Two Million").
